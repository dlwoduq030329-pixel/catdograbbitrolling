# 전투 흐름과 데이터 참조

## Scene 초기화

1. `BattleSceneInstaller`가 DataPool, Registry와 누락된 Battle 서비스를 준비한다.
2. 캐릭터 선택 UI에서 Player 프리팹을 생성한다.
3. `BattlePlayerRegistrationService`가 Player Body와 자식 모델을 등록한다.
4. `BattlePlayerRuntimeDataFactory`가 HP, MP, 공격 데이터를 자동 구성한다.
5. 선택 후 카메라 이동이 끝나면 `BattleUIFlowController`가 Player Select를 끄고 Battle Canvas를 켠다.

## Player 턴

1. 턴 시작 시 Current MP를 Max MP로 회복하고 Dice 버튼을 활성화한다.
2. 주사위를 굴려야 행동 입력과 End Turn이 열린다.
3. Player 클릭 시 이동 범위와 이동 후 공격 위협 범위를 표시한다.
4. 이동은 타일 우클릭 → Confirm/Quit 순서다. Quit는 범위 선택 단계로 돌아간다.
5. 이동 MP는 실제 타일 경로 1칸당 1을 확정 직전에 다시 검사한다.
6. 기본 공격과 카드는 대상/타일 선택 → 효과 범위 → Confirm/Quit 순서다.
7. 카드 행동 중에는 Tab 닫기를 잠가 범위 레이어와 행동 상태가 어긋나지 않게 한다.

## Enemy 턴

1. `BattleEnemyTurnRunner`가 등록된 Enemy를 순서대로 실행한다.
2. 각 Enemy는 Behavior Tree에서 공격 가능 → 이동 가능 → 대기 순으로 판단한다.
3. `MapPathfinder`가 점유 타일을 피해 Target까지의 최단 경로를 계산한다.
4. 이동은 칸당 1 MP를 사용한다.
5. 일반 Enemy 공격은 특수 기믹이 없는 한 턴당 1회다.
6. Enemy가 모두 끝나면 Player 턴으로 복귀한다.

## 카드 데이터 흐름

`CardDatabaseLegacy.asset`의 카드 번호 → `BattleCardConnector` → `PlayerCardMain.asset`의 전투 데이터 → `BattleCardDrawSystem` 손패 → `BattleCardActionController` 대상 선택 → `BattleCardEffectPipeline` 검증·실행 → `BattleDamageService`/이동·상태 서비스

중요: MP 차감과 카드 제거는 효과 실행 가능 여부가 확정된 뒤 한 번만 수행해야 한다.

## 카드 범위 표시 계층

1. R Enemy 감지 범위: 최하단 정보 레이어
2. Player 이동 가능 범위
3. 이동 후 공격 위협 범위
4. 카드 사용 가능 사거리
5. 선택 대상 기준 실제 효과 범위
6. 목적지·밀치기 프리뷰

레이어가 남거나 중첩되면 새 색을 추가하지 말고 행동 취소/상태 전이 시점의 정리 호출부터 확인한다.

## HP와 상태

- Player와 Enemy는 `BattleHealth`를 공용으로 사용한다.
- 피해는 `BattleDamageService`를 통해 적용한다.
- 보호막이 있으면 보호막부터 감소한다.
- Enemy HP가 0이면 점유에서 즉시 제외하고 시각 오브젝트는 페이드 후 제거한다.
- Stun은 해당 Enemy 턴 행동 전체를 막는다.
- Root는 이동을 막고 가능한 공격은 허용한다.
- Vulnerable은 받는 피해를 25% 증가시킨다.

## 카메라 입력

- 마우스 휠: 줌
- 맵 드래그/지정 입력: 패닝
- Space: Player 중심 포커스, 길게 누르면 홀드
- 이동 Confirm 후: Player를 화면 중앙에 홀드한 상태로 이동을 따라간다.
- UI 버튼 위에서는 Space가 버튼 클릭으로 전달되지 않아야 한다.

## 상자 보상 흐름

1. Player가 Box 타일에 도착하면 레거시 상자 UI를 연다.
2. 미니게임 없이 상자 낙하·개봉 연출을 순서대로 실행한다.
3. 보상 후보 카드를 결정하지만 이 시점에는 보유 수량을 변경하지 않는다.
4. 상자 안에 원본 카드 이미지를 표시한다.
5. 카드 이미지를 클릭하면 보유 수량을 1 증가시키고 상자 UI를 닫는다.
6. ESC로 닫은 경우 같은 Box 타일에서 동일한 보상을 다시 열 수 있다.
