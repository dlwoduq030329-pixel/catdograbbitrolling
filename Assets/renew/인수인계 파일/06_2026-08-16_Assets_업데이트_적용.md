# Assets 업데이트 적용 기록

기준일: 2026-08-16

## 목적

전달받은 Assets 업데이트를 현재 프로젝트의 기존 작업을 보존하면서 병합하고, 코드 및 데이터 호환성을 검증한다.

## 적용 내용

- 입력 경로: `C:/Users/user/Downloads/Assets`
- SHA-256 비교 결과가 다른 신규 14개, 변경 23개 등 총 37개 파일만 적용했다.
- 전달 폴더에 없는 현재 프로젝트 파일은 삭제하지 않았다.
- 변경 전 23개 파일은 `.codex-backups/Assets_update_20260816_before`에 상대 경로 그대로 백업했다.
- 전체 적용 목록은 백업 폴더의 `applied_manifest.csv`에 기록했다.

## 호환성 수정

- 적 데이터의 행동력 필드가 `maxMP`에서 `maxTurnMP`로 변경되어 기존 위협 범위 계산에서 CS1061 오류가 발생했다.
- `BattlePlayerRangeController`의 최대 이동 위협 범위를 `maxTurnMP / moveMPCostPerTile` 기준으로 계산하도록 연결했다.
- 기존 Public API를 추가하거나 원본 맵 코드를 수정하지 않았다.

## 검증 결과

- 신규 스크립트 3개를 포함한 전체 C# 정적 컴파일 성공.
- 컴파일 오류 0개, 기존 경고 24개.
- 업데이트 파일 37개의 적용 후 SHA-256 불일치 0개.
