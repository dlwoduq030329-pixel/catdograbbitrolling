# 폴더별 코드 설명

## renew 메인 폴더

| 폴더 | 소유/수정 원칙 | 용도 |
|---|---|---|
| `Battle` | 전투팀 작업 영역 | 턴, 이동, AI, 카드, 전투 데이터, 전투 UI를 구현한다. |
| `Scripts_map` | 맵 원본 우선 | 맵 생성, `MapInfo`, 타일 타입과 연결 정보를 제공한다. Battle은 이를 읽어 사용한다. |
| `share` | 공용 UI 원본 우선 | 캐릭터 선택, 카드 인벤토리, 레거시 데이터·UI 연결을 제공한다. |
| `animator` | 공동 자산 | 캐릭터 애니메이터 관련 자산이다. AnimationEvent 호환은 Battle Bridge가 담당한다. |
| `인수인계 파일` | 공동 문서 | 구조, QA, 카드 현황과 작업 규칙을 보관한다. |

## Battle/Core

- `BattleGameManager`: 플레이어/적 턴, 주사위, 현재 Player, 공용 전투 시스템 연결을 총괄한다.
- `BattleActionData`: 이동·공격·카드 행동 요청에 필요한 공용 값 객체다.
- `CharacterMP`: Max MP와 Current MP를 관리하고 행동 전 검사·차감을 수행한다.
- `BattleComponentResolver`: Player 자식 모델과 컴포넌트를 안전하게 탐색한다.
- `BattleCharacterAnimationBridge`: 전투 행동을 캐릭터 애니메이션에 전달한다.
- `BattleLegacyAnimationEventReceiver`: 레거시 AnimationEvent의 수신 누락 경고를 막는 호환 계층이다. 실제 피해는 처리하지 않는다.

## Battle/Context

- `BattleDataPool`: 주요 런타임 시스템·데이터 참조를 한곳에서 공유한다.
- `BattleSceneInstaller`: Scene 시작 시 필요한 Battle 컴포넌트를 생성·연결한다.
- `BattleMapRegistry`: `MapInfo` 좌표와 타일 조회를 제공한다.
- `BattleUnitRegistry`: Player, Enemy, 소환물의 점유 정보와 조회를 제공한다.

## Battle/Player

- `BattlePlayerActionController`: Player 행동 흐름의 진입점이다. 입력 결과를 이동·공격·카드 시스템으로 전달한다.
- `BattlePlayerInputReader`: 키보드와 마우스 입력을 읽는다.
- `BattleRaycaster`: 화면 좌표에서 Player, Enemy, Tile을 판별한다.
- `BattlePlayerRangeController`: 이동·공격·위협 범위 표시 상태를 조정한다.
- `BattleRangeVisualizer`: 타일 레이어의 생성, 색, 투명도와 제거를 담당한다.
- `BattleTileRangeCalculator`: 타일 연결 기준 거리와 범위를 계산한다.
- `BattleMovementController`: 이동 선택, Confirm/Quit와 MP 검사를 조율한다.
- `BattlePlayerMover`: 확정된 경로를 따라 Player를 이동시킨다.
- `BattleMovePreview`: 선택 목적지와 이동 프리뷰를 관리한다.
- `BattlePlayerMapContext`: Player가 사용하는 맵·점유 조회를 묶는다.
- `BattlePlayerTurnActionState`: 현재 턴의 이동·공격·카드 진행 상태를 기록한다.
- `BattlePlayerRegistrationService`: 생성된 Player Body와 모델을 전투 시스템에 등록한다.
- `BattlePlayerRuntimeDataFactory`: Player 스폰 시 MP·HP·전투 데이터를 자동 부착한다.
- `PlayerCombatData`: Player 공격 사거리 등 전투 수치를 보관한다.
- `BattleUnitHoverHighlighter`: 마우스가 올라간 유닛의 시각 강조를 담당한다.

## Battle/Enemy 및 AI

- `EnemySpawner`: ENEMY 타일 위에 Enemy를 생성하고 시작 성역 범위에서는 스폰하지 않는다.
- `EnemyDetector`: Player 감지와 감지 범위 표시를 담당한다.
- `EnemyTurnActor`: Enemy 한 개의 턴 행동을 시작하고 제어 상태를 반영한다.
- `BattleEnemyTurnRunner`: 여러 Enemy의 행동 순서를 실행한다. 속도 시스템 전에는 등록 순서가 기본 기준이다.
- `BattleEnemyActionExecutor`: 이동·공격처럼 결정된 Enemy 행동을 실제 실행한다.
- `BattleEnemyMapContext`: Enemy용 맵과 점유 정보를 제공한다.
- `BattleEnemyTargetBroker`: Player·허수아비 등 현재 추적 대상을 선택한다.
- `BattleEnemyControlState`: Stun과 Root의 남은 턴을 관리한다.
- `BattleEnemyDeathHandler`: 사망 Enemy를 즉시 삭제하지 않고 페이드 후 정리한다.
- `BehaviorTreeCore`: Selector, Sequence, Condition, Action의 공용 노드 기반이다.
- `EnemyBehaviorTree`: 공격·이동·대기의 우선순위를 판단한다.
- `EnemyAIContext`: AI 판단에 필요한 Enemy, Target, MP, Map 참조를 전달한다.
- `EnemyAwareness`: 감지와 피격 공유로 Player 인식을 관리한다.
- `MapPathfinder`: 타일 연결과 점유를 고려한 최단 경로를 계산한다.
- `PathDebugView`: Enemy 추격 경로를 디버그용으로 표시한다.

## Battle/Cards 및 CardData

- `BattleCardDrawSystem`: 턴 시작 드로우, 손패, 카드 사용 시작과 제거를 관리한다.
- `BattleCardActionController`: 카드 대상 선택, 범위 표시, Confirm/Quit와 실행 요청을 조율한다.
- `BattleCardEffectPipeline`: 피해·회복·보호막·상태·이동·소환·영역 효과를 순서대로 검증하고 실행한다.
- `BattleCardMovementService`: 돌진, 순간이동, 밀치기와 충돌 결과를 처리한다.
- `BattleLegacyCardPresentationBridge`: 레거시 애니메이션과 VFX만 Battle 실행에 연결한다.
- `BattleCardVfxRegistry`: 카드 코드별 VFX 프리팹을 찾는다.
- `BattleHealingArea`: 성역화의 3×3 지속 영역, 회복과 표시 수명을 관리한다.
- `BattleScarecrowSummon/Bridge/PrefabReference`: 허수아비 생성, 점유, 도발 대상 연결을 담당한다.
- `BattleCardDatabase`: 실제 전투 카드의 대상·사거리·효과 목록 형식이다.
- `BattleCardMasterDatabase`: 0~27 카드 기획 기준표다. 런타임에 직접 연결되지 않는다.
- `BattleCardConnector`: 원본 카드 번호로 이미지·MP 데이터와 Battle 데이터를 연결한다.

## Battle/Combat

- `BattleHealth`: 현재 HP, 최대 HP, 보호막과 사망 상태를 관리한다.
- `BattleDamageService`: 피해 적용의 단일 진입점이다.
- `BattleStatusEffects`: Vulnerable 등 공용 상태이상과 지속 턴을 관리한다.
- `BattleBasicAttackController`: Player 기본 공격의 선택·확정 흐름을 담당한다.
- `BattleBasicAttackService`: 실제 공격 가능 여부와 피해 실행을 담당한다.
- `BattleAttackCostService`: 기본 공격 MP 비용을 계산한다.
- `BattleBasicAttackBuff`: 기본 공격 강화 상태를 기록한다.

## Battle/UI

- `BattleUIFlowController`: Player Select와 Battle Canvas 전환을 담당한다.
- `BattleActionConfirmView`: 이동·공격·카드가 공유하는 Confirm/Quit 패널이다.
- `BattleTurnButtonController`: Dice와 End Turn 버튼 상태·이미지를 전환한다.
- `BattleCardHandView`: 고정된 카드 버튼 5개에 손패 이미지와 입력을 연결한다.
- `BattleCardPanelToggle`: Tab 카드 패널 열기·닫기와 행동 중 잠금을 처리한다.
- `BattleCardInfoPresenter/LongPressHandler`: 카드를 길게 눌렀을 때 확대 이미지와 정보를 표시한다.
- `BattleEnemyStatusView/InspectView`: Enemy HP·상태와 상세 정보를 표시한다.
- `BattlePlayerPortraitStatusView`: Player 초상화 위 HP·보호막 링을 갱신한다.
- `BattleHealthBarFactory/View`: Enemy 체력 바 생성과 실시간 갱신을 담당한다.
- `BattleMoveThreatPreview`: 이동 가능 영역 끝의 공격 위협 범위를 표시한다.
- `BattlePushPreviewView/Config`: 밀치기 결과와 충돌 예상 위치를 표시한다.
- `BattlePointerSelectionClearer`: ESC·범위 밖 입력의 선택 정리를 돕는다.
- `PlayerMPUI`: Filled Image와 현재/최대 MP 표시를 연결한다.

## Battle/Camera, Map, Movement, Rewards, Shop

- `BattleCameraRig`: Player 포커스와 카메라 이동 상태를 총괄한다.
- `BattleMapCameraInput`: 휠 줌, 맵 패닝과 Space Player 홀드를 처리한다.
- `CameraFollow`: 선택·이동 중 Player 추적을 보조한다.
- `BattleTileLocator`: 월드 위치에서 가장 가까운 `MapInfo`를 찾는다.
- `BattleMapTraversalService`: 물·장애물·유닛 점유를 반영해 이동 가능 여부를 판단한다.
- `Tile`: Battle 이전 임시 타일 호환 코드다. 실제 맵 기준은 Scripts_map의 `MapInfo`다.
- `BattleTransformMovement`: 공용 Transform 이동 코루틴이다.
- `BattleChestRewardSystem`: Box 타일 진입 시 레거시 상자 개봉 연출을 실행하고, 표시된 카드 클릭 시 보상을 지급한다.
- `BattleLegacyChestPrefabReference`: 원본 상자 개봉 프리팹을 직접 수정하지 않고 Battle에 제공한다.
- `BattleCardShopSystem`: Store 타일 진입, 상품 3장, 골드, 구매·리롤을 관리한다.
- `BattleLegacyStorePrefabReference`: 원본 `Store.prefab` 외형 참조를 제공한다.
- `BattleLegacyStoreViewAdapter`: 원본 프리팹의 `StoreManager`가 직렬화한 실제 판매 슬롯·골드·리롤 참조를 Battle 상점에 연결한다.
