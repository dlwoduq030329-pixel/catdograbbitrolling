## 2026-08-13 상점 표시 수정

- Store 타일 진입 호출과 구매 로직은 정상 실행되는 것을 로그로 확인했다.
- 프리팹 전체 검색으로 선택한 첫 3개 슬롯이 실제 판매 슬롯이 아니라 비활성 인벤토리 슬롯일 수 있는 문제를 수정했다.
- `StoreManager`에 직렬화된 실제 판매 슬롯 3개와 카드 이미지, 이름, 가격, 골드, 리롤 참조를 전용 어댑터로 연결했다.
- 정적 컴파일: 오류 0개, 기존 포함 경고 23개.
- Play Mode 확인 필요: Store 타일 도착 시 기존 Store 배경과 실제 판매 카드 3장이 표시되는지 확인한다.

## 2026-08-13 레거시 상자 흐름 조사

- 현재 Battle 상자는 Box 타일 도착 즉시 카드를 지급하고 2.5초 동안 임시 텍스트 UI를 표시한다.
- 레거시 상자는 `Treasure` → `OrbitTimingGame` → 성공 판정 → 상자 개봉 → 보상 이미지 표시 → 보상 획득 순서다.
- 레거시 상자 외형은 `Assets/Game/UI/UITexture/Event_Treasure/TreasureChest_Start.prefab`에 있다.
- 미니게임은 `Assets/Game/Board/Lockpit/OrbitTimingGame.prefab`과 `OrbitTimingGame.cs`가 담당한다.
- 카드 보상 이미지는 `Treasure.GetAward()`가 원본 카드 데이터의 Sprite를 `rewardIMG`에 적용한다.
- 현재 Battle 구현은 레거시 미니게임·상자 개봉 이미지·보상 클릭 획득 단계를 우회하므로 교체가 필요하다.
- 확정 변경: 자물쇠 미니게임은 사용하지 않는다.
- 구현 흐름: Box 타일 진입 → 상자 개봉 → 카드 이미지 표시 → 이미지 클릭 시 획득.
- 획득 전에는 카드 보유 수량을 변경하지 않으며 ESC로 닫으면 동일한 보상을 다시 표시한다.
- 정적 컴파일: 오류 0개, 기존 포함 경고 23개.
- Play Mode 확인 필요: 개봉 연출, 카드 이미지, 클릭 획득 1회, ESC 재진입을 확인한다.

# 2026-08-16 상점·상태창·턴 연출 QA 추가

## 2026-08-16 전투 진입·적 턴 회귀 수정

- TURN 1은 호출 경로와 관계없이 플레이어 턴 페이드를 재생하지 않는다. 전투 입장 페이드 한 번만 사용한다.
- 맵 생성 완료 프레임부터 최상위 투명 입력 차단막을 활성화해 HUD 버튼 연타를 차단한다.
- 실제 이동 또는 공격을 시작한 적만 카메라가 추적한다.
- 행동하지 않은 적은 카메라 포커스를 변경하지 않는다.
- 적 행동 하나가 10초를 초과하면 해당 행동을 안전 종료하고 다음 적 또는 플레이어 턴으로 진행한다.
- 적 이동 시간은 비보정 시간을 사용해 Time.timeScale 때문에 적 턴이 영구 정지하지 않게 한다.
- 적이 행동하지 않아 플레이어 턴 전환 연출을 생략할 때도 플레이어 이동·선택과 카메라 입력을 즉시 복구한다.
- 적이 행동하지 않은 경우 페이드는 생략하지만 `PLAYER TURN / TURN X` 문구는 표시해 턴 복귀를 명확히 알린다. 문구는 입력을 잠그지 않는다.

### 회귀 QA

- [ ] 전투 입장부터 TURN 1 시작까지 페이드 인·아웃 묶음이 정확히 한 번만 발생한다.
- [ ] 맵 생성 직후 HUD 버튼을 연타해도 인벤토리와 캐릭터 정보창이 열리지 않는다.
- [ ] 감지 대상이 없거나 행동할 수 없는 적은 카메라가 따라가지 않는다.
- [ ] 모든 적이 행동하지 않으면 추가 플레이어 턴 페이드 없이 조작권이 즉시 돌아온다.
- [ ] 무연출 플레이어 턴에서 주사위뿐 아니라 플레이어 선택, 이동 범위 표시, 타일 선택이 모두 가능하다.
- [ ] 적 행동 중 문제가 발생해도 최대 10초 뒤에는 적 턴이 종료된다.

## 플레이어 턴 페이드 전환 추가

- 플레이어 턴 시작 시 `LoadingCanvas`를 활성화하고 화면을 암전한다.
- 완전히 암전된 순간 카메라의 적 임시 추적과 수동 이동값을 제거하고 플레이어 중심으로 즉시 복귀한다.
- 화면이 다시 밝아지는 동안 `PLAYER TURN / TURN X`를 함께 표시한다.
- 페이드와 턴 문구가 모두 끝난 뒤에만 카메라와 전투 입력을 다시 허용한다.
- 게임 일시정지 상태에서도 전환이 멈추지 않도록 페이드는 비보정 시간을 사용한다.
- Battle Canvas가 처음 활성화되는 프레임부터 Stage 및 첫 Player Turn 연출이 끝날 때까지 전체 UI, 월드 입력, 카메라 입력을 잠근다.

### 추가 QA

- [ ] 플레이어 턴마다 검은 화면 전환이 한 번만 실행된다.
- [ ] 암전 뒤 화면이 밝아질 때 카메라가 이미 플레이어 중앙에 있다.
- [ ] 밝아지는 동안 `PLAYER TURN / TURN X`가 표시된다.
- [ ] 전환이 끝나기 전에는 드래그, 휠, 타일 및 플레이어 입력이 작동하지 않는다.
- [ ] 전환 종료 후 카메라와 전투 입력이 정상적으로 복구된다.
- [ ] 캐릭터 선택 직후 Battle Canvas가 나타나는 순간 프로필, 카드, 턴 버튼 등 UI를 눌러도 반응하지 않는다.
- [ ] 첫 Player Turn 페이드가 끝난 뒤에만 Battle UI 입력이 허용된다.
