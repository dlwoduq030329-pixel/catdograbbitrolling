# 2026-08-14 Codex 작업 보고서

## 작업 원칙

- Codex가 프로젝트 변경을 담당하고 Claude는 정적 검수 용도로 사용한다.
- `Assets/renew/share`, `Assets/renew/Scripts_map`은 수정하지 않는다.
- 인벤토리 시스템은 아직 구현하지 않는다.
- 배포 ZIP은 사용자가 명시적으로 요청할 때만 생성한다.

## 1. 상점

- `Event_Store.prefab`을 전투 상점 화면으로 연결했다.
- 판매 슬롯은 6개를 모두 사용한다.
- 카드 3개와 장비 3개를 기본 구성으로 하되 후보 부족 시 다른 상품군 또는 기존 후보로 빈칸을 보충한다.
- 상품명, 보유량, 장비 스탯 문구는 판매 목록에서 제거하고 가격만 한 줄로 표시한다.
- 카드 이미지는 슬롯 중앙 기준 1.08배 확대했다.
- 리롤 가격은 10G에서 시작해 두 배씩 증가하며 최대 160G다.
- 카드와 장비는 가능한 범위에서 중복을 피하고, 현재 착용 중인 장비는 출현 가중치를 1/4로 낮췄다.
- 한손 장비 구매 시 왼손과 오른손을 직접 선택한다.
- 장비 가격은 종류별 기본 가격과 등급 배율로 계산한다.

## 2. 포션 분류 확인

- `HEALING_POTION`, `POISON_POTION`은 `EquipDatabase` 장비가 아니다.
- 두 포션은 카드 DB에 등록된 소비형 카드이며 카드 스킬로 실행된다.
- 상점의 동일한 6칸 목록에 카드와 장비가 섞여 표시되어 장비처럼 보였을 뿐이다.
- 따라서 포션을 장비 교체 시스템에서 분리하는 별도 변경은 하지 않았다.

## 3. 전투 상자

- 자물쇠 이벤트는 구현하지 않았다.
- 상자 낙하 후 2.05초를 기다리고 열림 애니메이션을 실행한다.
- 카드와 장비 후보가 모두 있으면 카드/장비를 50:50으로 결정한다.
- 카드 후보가 없으면 장비, 장비 후보가 없으면 카드로 대체한다.
- 둘 다 없으면 25G 보상으로 대체한다.
- 자동 획득을 제거하고 보상 이미지를 클릭해야 획득된다.
- 한손 장비는 왼손/오른손 선택 후 획득한다.
- 몸·머리·양손 장비는 장착 확인 후 획득한다.
- 보상 선택 중에는 ESC와 배경 입력으로 닫히지 않는다.

## 4. 이벤트 입력 잠금

- 상점이나 상자가 열린 동안 주사위, 턴 종료, 맵 클릭, 카드 사용을 차단한다.
- 이벤트 종료 시 전투 입력을 복구한다.
- 중복 진입과 중복 잠금 해제를 방지한다.
- 플레이어 사망과 BattleGameManager 제거 시 이벤트 UI 및 잠금 상태를 정리한다.

## 5. 적 MP

- 적은 매 턴 `minTurnMP`와 `maxTurnMP` 사이에서 MP만 무작위로 결정한다.
- 이동 1칸 비용과 공격 비용은 기존 고정값을 유지한다.
- 기본 공격은 적 하나당 턴당 정확히 한 번으로 제한한다.
- MP가 소비되지 않거나 행동이 불가능하면 즉시 해당 적의 턴을 종료한다.
- 적 머리 위 상태 UI에 현재 MP/최대 MP를 표시한다.
- Q를 누른 채 적을 클릭하면 현재 MP, 추첨 범위, 최대 이동, 공격 거리와 공격력을 표시한다.

## 6. 카드 사용 후 성역화 이미지 표시 버그

- 카드 사용 직후 손패 목록을 당겨 그리면서 소비된 슬롯이 레거시 기본 이미지인 성역화처럼 보이는 문제가 있었다.
- 사용한 카드는 해당 턴 동안 원래 슬롯과 스프라이트를 유지한다.
- 사용 완료 슬롯은 어두운 회색으로 표시하고 클릭을 차단한다.
- 다음 플레이어 턴 시작 시 남은 손패와 사용 슬롯을 정리하고 새 손패를 뽑아 실제 카드 스프라이트로 교체한다.
- 이상한 버섯처럼 사용 즉시 대체 카드를 생성하는 효과는 같은 슬롯을 즉시 새 카드로 교체한다.
- 이상한 버섯으로 생성된 카드는 청록색 강조 테두리를 표시해 일반 드로우 카드와 구분한다.
- 생성 카드를 사용하거나 다음 플레이어 턴이 시작되면 강조 테두리를 제거한다.

## 7. 적 대상 카드 활성 조건

- 공격 카드와 적/캐릭터 대상 카드는 현재 사거리 안에 살아 있는 적이 있을 때만 버튼을 활성화한다.
- 전체 적 대상 카드는 살아 있는 적이 한 명 이상 있을 때만 활성화한다.
- 자기 자신 또는 일반 보조 카드는 적 유무와 관계없이 기존 사용 조건을 유지한다.
- 플레이어와 적의 타일을 기준으로 상하좌우 연결 거리를 계산하며 단순 월드 거리로 판정하지 않는다.
- 적 이동과 사망에 대응하도록 플레이어 턴 동안 0.2초 간격으로 카드 버튼 상태를 갱신한다.
- UI 이외의 코드 경로로 카드 사용이 요청되더라도 유효한 적이 없으면 다시 차단한다.

## QA 필요 항목

1. 상점 6칸이 모든 상점과 리롤 결과에서 채워지는지 확인한다.
2. 판매 목록에 가격 이외의 문구가 겹쳐 나오지 않는지 확인한다.
3. 상점과 상자 진행 중 주사위·턴 종료·맵 클릭이 차단되는지 확인한다.
4. 카드 상자 보상을 클릭한 뒤 카드 수량이 한 번만 증가하는지 확인한다.
5. 한손 장비 상자 보상에서 왼손/오른손 선택이 정확히 적용되는지 확인한다.
6. 몸·머리·양손 장비 교체 후 외형과 능력치가 즉시 갱신되는지 확인한다.
7. 적 MP가 설정 범위 안에서 매 턴 바뀌며 공격이 두 번 발생하지 않는지 확인한다.
8. 플레이어 사망 또는 씬 종료 시 이벤트 입력 잠금이 남지 않는지 확인한다.
9. 카드 사용 후 해당 카드가 같은 슬롯에서 어둡게 표시되고 재사용할 수 없는지 확인한다.
10. 다음 플레이어 턴에 어두운 사용 카드가 새 카드 스프라이트로 교체되는지 확인한다.
11. 이상한 버섯 생성 카드에 청록색 테두리가 표시되고 다음 턴에 제거되는지 확인한다.
12. 적이 카드 사거리 밖에 있을 때 공격·적 대상 카드 버튼이 비활성화되는지 확인한다.
13. 적이 사거리 안으로 들어오거나 제거됐을 때 카드 버튼 상태가 즉시 바뀌는지 확인한다.

- 현재 환경에는 .NET SDK가 없어 외부 `dotnet build`를 실행할 수 없다.
