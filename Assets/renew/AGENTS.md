# Renew 작업 규칙

## 인수인계 문서 동기화

`Assets/renew` 아래에서 기능 추가, 버그 수정, 데이터 변경, 파일 이동 또는 QA를 수행한 경우 같은 작업에서 `Assets/renew/인수인계 파일`을 갱신한다.

- 폴더·스크립트 역할 변경: `01_폴더별_코드_설명.md`
- 실행 흐름·참조 구조 변경: `02_전투_흐름과_데이터_참조.md`
- 구현 상태·QA 결과 변경: `03_현재_개발단계_QA.md`
- 협업 경계·수정 원칙 변경: `04_협업_규칙과_주의사항.md`
- 카드 데이터·효과·QA 변경: `카드_데이터_및_구현현황.xlsx`

문서는 공식 개발 문서 형식을 유지한다. 대화체, 개인 이름, 작업 도구 이름, 감상 또는 비공식 평가를 기록하지 않는다.

## 수정 경계

- `Scripts_map`과 `share`는 호환성 확인 없이 수정하지 않는다.
- 레거시 원본은 직접 변경하기보다 Battle의 Bridge, Reference 또는 Adapter를 우선한다.
- 기존 Public API는 사용처 확인과 리뷰 없이 변경하지 않는다.
- 컴파일 성공만으로 완료 처리하지 않고 Play Mode QA 결과를 기록한다.
