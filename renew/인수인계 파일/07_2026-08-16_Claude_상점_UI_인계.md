# 상점 UI 안정화 작업 인계

## 목적

기존 `Event_Store` 프리팹 외형과 UI 배열을 유지하면서 Battle 상점 로직을 안정화한다. 레거시 게임 로직은 실행하지 않고 표시 요소만 재사용한다.

## 주요 코드

- `Assets/renew/Battle/Shop/BattleCardShopSystem.cs`
- `Assets/renew/Battle/Shop/BattleLegacyStoreViewAdapter.cs`
- `Assets/renew/Battle/Shop/BattleShopOfferHover.cs`
- `Assets/renew/Battle/Core/BattleGameManager.cs`
- `Assets/renew/Battle/Event_Store.prefab`

## 완료된 변경

1. 상점 진입 시 `HUDCanvas`와 상점 외 Battle UI를 숨기고 종료 시 기존 상태로 복원한다.
2. 판매 상품 이미지와 가격을 Battle 카드·장비 데이터로 갱신한다.
3. 상품 호버 시 태그, 속성, 피해, 장비 능력치와 선택 이미지를 표시한다.
4. 호버가 없으면 `SelectedImage`와 기본 `CardName`을 숨긴다.
5. 보유 카드와 장착 장비를 상점 인벤토리에 표시한다.
6. `EquipStore.Init()`의 `DataPool` 의존 호출을 제거하여 NullReferenceException을 방지한다.
7. 리롤 버튼 이벤트를 교체하여 레거시 `StoreManager.reload()`의 중복 호출을 제거한다.
8. 상품 클릭 시 기존 `BuySellButton`을 표시하고 해당 버튼에서 구매를 확정한다.
9. 인벤토리 레이아웃을 갱신하고 시작 위치를 맨 위로 설정했다.
10. 인벤토리 마우스 휠 감도를 25로 설정했다.

## 즉시 필요한 Play Mode QA

- [ ] 상점 진입 시 `EquipStore.Init` 예외가 발생하지 않는다.
- [ ] 리롤 한 번 클릭에 상품과 가격이 한 번만 변경된다.
- [ ] 상품 클릭 시 `BuySellButton`이 표시된다.
- [ ] 구매 버튼 클릭 시 선택한 상품만 구매된다.
- [ ] 인벤토리가 맨 위에서 시작한다.
- [ ] 카드 위에서도 마우스 휠 스크롤이 작동한다.
- [ ] 보유 카드와 왼손, 오른손, 머리, 몸 장비 이미지가 실제 데이터와 일치한다.
- [ ] 상점 진입 시 HUD가 전부 사라지고 ESC 종료 시 기존 상태로 복원된다.
- [ ] 호버 종료 시 `SelectedImage`와 카드 이름이 사라진다.
